# YAGNI

An agent skill for reviewing plans, code, and workflows with YAGNI, KISS, and DRY. Remove speculative work while preserving requirements, correctness, and validation.

## Install

Copy `SKILL.md`, `references/`, and `agents/` into your agent's skills directory under `yagni/`.

## Use

```text
$yagni Review this implementation for unnecessary abstractions.
```

See [SKILL.md](SKILL.md) for the instructions and [references/](references/) for worked examples and sources.
