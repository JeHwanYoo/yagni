# YAGNI

An agent skill for reviewing plans, code, and workflows with YAGNI, KISS, and DRY. Remove speculative work while preserving requirements, correctness, and validation.

## Install

Clone this git project into your skills folder.

```bash
# Codex path: ~/.codex/skills/yagni
# Claude path: ~/.claude/skills/yagni
# Gemini path: ~/.gemini/skills/yagni
# Cursor path: ~/.cursor/skills/yagni
# Copilot path: ~/.copilot/skills/yagni
# OpenCode path: ~/.config/opencode/skills/yagni

git clone https://github.com/JeHwanYoo/yagni.git <your-skills-folder>/yagni
```

## Use

```text
$yagni Review this implementation for unnecessary abstractions.
```

See [SKILL.md](SKILL.md) for the instructions and [references/](references/) for worked examples and sources.
